# Mundane — Rulebook

*Magic: The Gathering without the, you know, magic.*

Welcome to Mundane, a game in which two households try to out-ordinary each other into oblivion. You
throw house parties, file noise complaints, adopt wholesome habits, and buy questionable appliances —
all to wear down your opponent's **Composure** until their household falls apart.

This rulebook explains how the game works in plain language, with examples. If you want the precise,
lawyerly version — the exact rejection messages, the order the engine checks things in — read the
[specification](../specs/) instead. The two describe the same game; the spec is the source of truth,
and this one is the friendlier translation.
